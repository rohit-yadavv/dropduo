# Roadmap

Priorities, not promised release dates. See [current evidence](validation.md) and [v1 scope](product.md).

- Validate physical-device pairing, camera scanning, discovery, transfers both ways, resume, sleep/wake, network changes, screen lock, and battery controls.
- Test large files, low storage, failed imports, repeated use, VoiceOver/TalkBack, keyboard navigation, large text, and translations.
- Review protocol security; an independent audit is outstanding.
- Establish notarized Mac distribution and consistent Android update signing, with required license notices.
- Use tester feedback to prioritize login launch, background reliability, batching, and clearer errors.

Extra platforms, browser transfer, clipboard sync, and internet relays need separate scope agreement. [Report a concrete problem or contribute](../CONTRIBUTING.md).
