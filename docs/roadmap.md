# Roadmap

## Alpha exit

Complete the physical-device release matrix, exercise failed imports and network breaks, review accessibility and translated strings, audit the pairing/transfer protocol, and establish signed Mac/Android distribution. Add required third-party license texts to release packages. Configure hosted CI and branch protection after creating a remote repository.

## Next usability work

Use real alpha feedback to prioritize Mac login launch, Android background reliability, batching UX, and discovery troubleshooting. Measure successful transfers and task completion through opt-in testing, not hidden analytics.

## Scope discipline

Extra desktop/mobile platforms, browser transfer, clipboard synchronization, and internet relay are separate proposals. Keep v1 focused on trustworthy Mac–Android sharing; each proposal needs a demonstrated everyday use case and an OS feasibility check.
