# Web contributor instructions

Read root AGENTS.md. Static marketing and download page: plain HTML, CSS and JavaScript with no framework or package install. Keep it dependency-free; vendor small open-licensed assets under assets/ with their license files and list them in docs/dependencies.md. Download links come from the GitHub Releases API at view time, so keep asset patterns in sync with docs/downloads.md. Honor prefers-reduced-motion and both themes. Run scripts/check web before committing.
